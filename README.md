# CS4200 A* 8 Puzzle Project

### Project Description: 
*This program solves a given puzzle configuration, either random or inputted, using the A\* algorithm with two options of heuristics. It tracks and reports the search cost, steps, and each move made. It requires the user to interact through the terminal.*
* Each run will track the solving steps of a single puzzle and print the search cost
* Each run will also generate a table of 100 random tests, solved with both H1 and H2 heuristics, in a file called "results.txt"

### How to run: 
* Unzip folder
* Open project directory in an IDE 
* Navigate to Main.java
* Run Main.main();
* Enter input through the terminal to choose input method and H function
